# Simple Contact Form

A clean, responsive contact form built with HTML and CSS.

## Project Overview

This project provides a simple yet elegant contact form that can be integrated into any website. The form includes fields for name, email, subject, and message. It's styled with a modern, minimalist design.

## Features

- Responsive design - works on desktop and mobile
- Form validation for required fields
- Clean and modern UI
- Simple JavaScript for form submission handling

## Running the Project

This project is configured to run in GitHub Codespaces. To get started:

1. Wait for the devcontainer to finish building
2. Use the VS Code Live Server extension to serve the project:
   - Click on "Go Live" in the status bar or right-click on `index.html` and select "Open with Live Server"

## Updating the Project with GitHub Copilot Agent Mode

This project can be updated efficiently using GitHub Copilot in agent mode within GitHub Codespaces. To enable and use Copilot agent mode:

1. Ensure that GitHub Copilot is enabled in your Codespaces environment.
2. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on Mac) and search for "GitHub Copilot: Enable Agent Mode."
3. Use natural language prompts to request code changes or enhancements directly in your editor.
4. Review and apply the suggested changes to your project files.

This allows for seamless integration of AI-assisted development into your workflow.
